# 界面概览

ComfyUI 的主界面可以分成五个区域。认全这五块，之后所有教程里的「点哪里」就都不再是障碍。

```text
┌─────────────────────────────────────────────────────┐
│ ① 顶部栏：Logo / 工作流标签页 / 运行按钮 / 设置入口   │
├────────┬────────────────────────────────────────────┤
│        │                                            │
│ ④ 侧边 │              ② 画布区域                    │
│   栏   │        （节点、连线、平移缩放）              │
│(队列/库)│                                            │
│        │                       ③ 右键菜单（空白处）  │
├────────┴────────────────────────────────────────────┤
│ ⑤ 底部状态：进度条 / 显存占用 / 提示信息               │
└─────────────────────────────────────────────────────┘
```

## ① 顶部栏

| 元素 | 说明 |
| ---- | ---- |
| 工作流标签页 | 像浏览器标签一样同时打开多个工作流，可拖动分屏（左右 / 上下布局） |
| 运行 / Queue Prompt | 把当前工作流加入执行队列，快捷键 `Ctrl + Enter` |
| 队列与历史 | 查看排队中与已完成的任务，可中断、重跑 |
| 设置（齿轮） | 主题、语言、画布行为、显存策略等几乎所有偏好项 |

## ② 画布：你的主战场

画布是无限延伸的工作台，常用手势：

| 操作 | 手势 / 快捷键 |
| ---- | ------------- |
| 平移画布 | 按住空白处拖动，或按住空格拖动 |
| 缩放 | 鼠标滚轮 |
| 框选 / 移动节点 | 左键拖出选框，拖动节点标题栏移动 |
| 添加节点 | 空白处**双击**打开搜索框，或右键 → Add Node |
| 连线 | 从输出圆点拖到输入圆点 |
| 断线 | 把线端拖到空白处松开，或点击输入口圆点 |
| 折叠节点 | 双击节点标题栏；折叠后只剩标题条，理画布神器 |
| 组管理 | 框选多个节点 → 右键 → 转换为组（Group），整组移动、整组着色 |

## ③ 右键菜单

在任何节点的标题栏或参数上右键，会弹出该节点可用的操作（转输入、固定值、克隆等）；在空白处右键则可新建节点、便签（Note）、分组。**多在空白处和节点上右键试试**，你会发现很多没写进文档的小功能。

## ④ 侧边栏面板

新版界面把常用工具收进左侧可收起的侧边栏：

| 面板 | 用途 |
| ---- | ---- |
| 队列 Queue | 当前任务与排队情况 |
| 节点库 Nodes | 按分类浏览全部节点（含已安装的自定义节点），拖到画布即用 |
| 模型库 Models | 浏览模型目录里的所有模型，同样可直接拖出创建加载节点 |
| 工作流库 Workflows | 管理保存过的工作流，官方模板也从这里进入（Browse Templates） |

## ⑤ 底部状态区

运行时显示整条流水线的执行进度（每个节点依次点亮），以及显存/内存占用提示。报错时，控制台（或界面上的错误弹窗）会指出**是哪个节点**出了问题——排错永远从被点名的节点开始。

## 高频快捷键速查

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl + Enter` | 运行 / 加入队列 |
| `Ctrl + S` | 保存当前工作流（JSON） |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |
| 双击空白 | 搜索并添加节点 |
| `R` | 刷新节点定义（装了新节点包后用） |
| 空格 + 拖动 | 抓手模式平移画布 |

:::note 版本差异
ComfyUI 的界面在快速迭代，不同版本的位置和叫法可能略有差异（例如旧版把运行按钮放在菜单区）。若本页描述与你的版本不一致，以设置里的实际项为准，功能逻辑是共通的。
:::
